Run the Strait Privacy Policy

Last updated: May 14, 2026

Run the Strait is an offline paid game. Version 1 does not use ads, in-app purchases, account login, analytics SDKs, social features, backend services, or third-party tracking.

Data Collection

Run the Strait does not collect personal data from players.

The game stores gameplay preferences, local scores, recent runs, and daily challenge progress on the device so the game can preserve settings and local records. This local data is not sent to the developer or to a game server.

Network Use

Gameplay does not require an internet connection. The Privacy and Support buttons may open the player's browser to public information pages.

Platform Services

Apple may process purchase, download, crash, diagnostic, or App Store usage information under Apple's own privacy practices. That platform data is not collected by Run the Strait.

Children

Run the Strait does not knowingly collect personal information from children.

Changes

This policy may be updated if a future version adds online services or data collection. Any material change will be reflected on this page.
