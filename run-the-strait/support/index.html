Run the Strait Support

Last updated: May 14, 2026

Run the Strait is an offline paid tactical action game for iPhone and iPad.

Quick Checks

  • The game is landscape-only.
  • Gameplay works offline after installation.
  • Scores, options, and daily challenge progress are stored locally on the device.
  • If controls feel wrong, open Options from the main menu and check Controls plus comfort and input settings.
  • If audio or visual effects are uncomfortable, use Options to lower volume, reduce shake, reduce flash, or enable readability options.

Troubleshooting

If the app will not launch, first restart the device and install the latest App Store version. If a problem happens during gameplay, note the device model, iOS or iPadOS version, app version, and what was happening when the issue appeared.
